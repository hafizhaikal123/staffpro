# User Stories

1. As an HR staff member, I want to manage employee information, so that employee records can be kept organized and up to date.

Acceptance criteria:

-I cannot save an employee record without the required employee details.
-A saved employee record appears in the employee list within 2 seconds.
-I can edit existing employee information and save the changes

2. As a staff member, I want to view my employee information so that I can check my personal details.

Acceptance criteria:

-The system displays the staff member's employee information.
-The system displays the latest saved information after changes have been made.

3. As an Admin/HR user, I want to manage employee leave records so that leave information can be tracked properly.

Acceptance criteria:

-The system displays the employee's leave records.
-The system displays the updated leave status after it has been saved.
