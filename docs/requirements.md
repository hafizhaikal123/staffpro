# Requirements

## Functional requirements
1. The system allows registered users to log in using valid account credentials.
2. The system allows Admin/HR to view, update and delete employee records.
3. The system allows authorized users to view employee information.
4. The system allows staff to view their attendance and leave records.
5. The system allows authorized users to manage employee leave applications.
6. The system allows authorized users to manage employee task assignments.

## Non-functional requirements
1. The system allows authorized users to manage employee task assignments.
2. The system allows authorized users to manage employee task assignments.
3. The login page will display a clear error message when invalid credentials are submitted, without showing whether the username or password was incorrect.
